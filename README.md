# ☁️ Cloud Engineer: Zero → Hero

> A futuristic 3D interactive roadmap platform designed to transform beginners into production-ready Cloud Engineers.



---

## 🚀 Overview

This project is a fully interactive **single-file learning platform** built using pure:

* HTML
* CSS
* JavaScript

No frameworks. No backend. No build tools.

The platform is designed for:

* Aspiring Cloud Engineers
* DevOps Engineers
* SRE learners
* Linux enthusiasts
* AWS beginners
* Interview preparation
* Hands-on cloud practice

The roadmap is structured to simulate the learning journey of a real-world engineer with approximately **3 years of industry-level cloud experience**.

# 🌍 Hosting on GitHub Pages

## 1. Create Repository

Go to:

[GitHub](https://github.com)

Create a new repository.

Example:

```bash
cloud-engineer-roadmap
```

---

## 2. Upload File

Upload:

```bash
index.html
```

---

## 3. Enable GitHub Pages

Go to:

```bash
Settings → Pages
```

Then:

* Source → Deploy from branch
* Branch → main
* Folder → /root

Save.

---

## 4. Access Website

Your site will be live at:

```bash
https://gagan-gk.github.io/cloud-Engineer
```
